# Palindrome Checker App (Java)

## 📌 Overview

This project demonstrates multiple approaches to check whether a string is a palindrome using different data structures and algorithms.

## 🚀 Use Cases Covered

* UC1: Basic Input & Output
* UC2: Hardcoded Palindrome Check
* UC3: String Reverse Method
* UC4: Character Array Method
* UC5: Stack-Based Approach
* UC6: Queue + Stack Approach
* UC7: Deque-Based Optimization
* UC8: Linked List Approach
* UC9: Recursive Method
* UC10: Case-Insensitive & Space Ignored
* UC11: Object-Oriented Design
* UC12: Strategy Pattern (Advanced)
* UC13: Performance Comparison

## 🧠 Concepts Used

* Strings & Arrays
* Stack, Queue, Deque
* Linked List
* Recursion
* OOP (Encapsulation, Polymorphism)
* Design Patterns (Strategy)
* Performance Analysis

## ▶️ How to Run

Compile:
javac UseCaseXPalindromeCheckerApp.java

Run:
java UseCaseXPalindromeCheckerApp

## 💡 Example Output

Input: madam
Output: Is Palindrome: true
