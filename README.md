# 🔁 Palindrome Checker App

## 📌 Overview
The Palindrome Checker App is a simple Java console application that checks whether a given string or number is a palindrome. A palindrome is a sequence that reads the same forward and backward.

---

## 🎯 Objective
To implement basic string and logic operations in Java while understanding user input handling and condition checking.

---

## ⚙️ Features
- Accepts user input (string or number)
- Reverses the input
- Compares original and reversed values
- Displays whether the input is a palindrome or not

---

## 🛠️ Technologies Used
- Java
- OOP Concepts
- String Handling
- Conditional Statements

---

## ▶️ How to Run

1. Open the project in IntelliJ IDEA / any Java IDE  
2. Navigate to the `src` folder  
3. Run the main class file  
4. Enter input when prompted  
5. View the result in console  

---

## 💡 Example

### Input:
madam
### Output:
It is a palindrome
